# Learning Log

## Week 2 – Time Series Exploration

This week I learned how to work with monthly rainfall time-series data.

I learned how to:
- convert dates into a time index
- check for missing values
- visualize a time series
- identify seasonal patterns
- compare monthly rainfall across years
- use seasonal and seasonal subseries plots

One important observation from the Phnom Penh rainfall dataset was that
September had the highest average monthly rainfall, while February had
the lowest average.

I also learned that an unusual observation should not automatically
be treated as an error without checking the source and metadata.
